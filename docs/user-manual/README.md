# HRMS User Manual

Welcome to the **Hrmsify** HRMS (Human Resource Management System) user manual.
This guide describes every feature module and the on-screen UI, organized module by module.

## Modules

| # | Module | File | What it covers |
|---|--------|------|----------------|
| 0 | Getting Started & App Overview | [00-getting-started.md](./00-getting-started.md) | Login, account recovery, app shell, navigation, search, permissions, user roles |
| 1 | People | [10-people.md](./10-people.md) | Employees, Employee Profiles, Departments, Designations, Org Hierarchy |
| 2 | Attendance | [20-attendance.md](./20-attendance.md) | Attendance log, Self check-in/check-out, Shifts, Holidays |
| 3 | Leave & Approvals | [30-leave.md](./30-leave.md) | Leave Requests, Leave Policies, Centralized Approval Center |
| 4 | Payroll | [40-payroll.md](./40-payroll.md) | Payroll runs, Salary structures, Payslips, PDF download |
| 5 | Recruitment | [50-recruitment.md](./50-recruitment.md) | Job Openings, Candidate pipeline (Kanban/Table), Interviews |
| 6 | Operations | [60-operations.md](./60-operations.md) | Performance, Expenses, Assets, Documents, Announcements |
| 7 | Insights | [70-insights.md](./70-insights.md) | Executive HR Analytics & Reports |

## Reading the manual

- Each module file lists the **pages/URLs**, the **UI elements** (exact on-screen labels), the **actions** you can perform, and the **permissions** required.
- A ⚠️ **"Currently not implemented"** note marks buttons or flows that exist in the UI but are not yet wired to a backend action.
- Badge colors and status meanings are explained in the [Appendix](./90-appendix.md).
